# [3장] 기본 사용법
### 주요 커맨드
- `init`
    - 테라폼 구성 파일이 있는 작업 디렉토리를 초기화하는 데 사용됨
    - 이 작업을 실행하는 디렉토리를 루트 모듈이라고 함
- `validate`
    - API 작업 없이 코드적인 유효성만 검사
- `plan & apply`
    - plan은 변경 사항에 대한 실행 계획 생성
        - `-detailed-exitcode`를 통해 동작의 결과를 0, 1, 2 로 반환 가능
        - `-out={name}` 을 통해 바이너리 파일로 반환 가능
    - apply는 계획을 기반으로 작업을 실행
        - `-out`으로 나온 파일 이름으로 plan 과정 없이 즉시 적용 가능
        - `replace`를 통해 변경 사항이 없어도 대상 리소스를 삭제하고 재생성 가능
- `destroy`
    - 테라폼 구성에서 관리하는 모든 개체를 제거
    - `auto-approve`로 apply와 destroy에서 yes 입력 없이 바로 적용 가능
- `fmt`
    - 표준 형식과 스타일로 포맷팅
